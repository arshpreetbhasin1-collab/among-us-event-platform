# Among Us Event Platform

Live multiplayer Among Us style event platform, built for a real college club event.

## Overview

A web-based recreation of the Among Us social deduction game, built to run as a live event for a college tech club. Supports multiple roles in the same session: players taking part in the game, an admin controlling the event, and spectators watching live.

## Features

Real-time multiplayer gameplay for live participants. A dedicated admin panel to control and moderate the event as it runs. A spectator view for attendees watching without playing.

## Tech stack

JavaScript, with real-time communication for live game state across player, admin, and spectator clients.

## Getting started

Clone the repo, run `npm install`, then run `npm run dev`.

## Project status

Built and used for a live college club event.
